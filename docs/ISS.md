# ISS Profilleri (Topluluk Tarafindan Dogrulanmis)

Bu tablo **kasitli olarak bos** birakilmistir. "TurkNet = kesin X profili"
gibi degerler internetten veya varsayimla uydurulmamistir; boyle bir
eslesme yalnizca gercek kullanici testleriyle anlamli hale gelir.

Kendi ISS'nizde hangi profilin calistigini test ettiyseniz (Otomatik Test
menusunu kullanarak veya elle), lutfen bir GitHub Issue acip asagidaki
formatla paylasin:

```
ISS               :
Baglanti turu      : (FTTH / VDSL / ADSL / GPON / diger)
IPv4               : (var/yok)
IPv6               : (var/yok)
CGNAT              : (var/yok/bilinmiyor)
Calisan profil     : (Stable / Compatibility / Strong)
Discord            : (calisiyor/calismiyor)
Roblox             : (calisiyor/calismiyor)
Steam              : (calisiyor/calismiyor)
Notlar             :
```
